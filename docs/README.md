## 근거와 상태 표기

기획 의도는 **최신 사용자 결정 → 이번 인수인계 → 이전 문서** 순으로 확인합니다. 구현 상태는 **현재 파일과 씬 연결 → 해당 변경에서 실제 수행한 검사 → 과거 사용자 실행 보고**를 각각 기록합니다. 코드에 없던 기능이 사용자 요청만으로 구현된 것은 아니며, 테스트 통과가 시각적 품질이나 완성도를 보장하지도 않습니다.

- **[확정]** 사용자가 결정한 게임 규칙.
- **[개발용]** 이번 구현을 확인하기 위한 키·수치·도형·콘텐츠. 최종 기획으로 승격하지 않음.
- **[기술 결정]** 현재 근거로 선택한 구현 방식. 게임 규칙과 구별해 재검토 가능.
- **[미정]** 사용자 판단이나 후속 설계가 필요한 내용.
- **[미구현]** 인터페이스가 있어도 실제 효과·영속 상태가 연결되지 않은 기능 포함.

이전 문서의 “Step 03 미설치”, “사용자 실행 보고 없음”은 최신 인수인계와 맞지 않아 갱신했습니다. 사용자는 가장 최근에 프로그램 실행에 문제가 없다고 보고했지만, 그 보고만으로 Step 03의 모든 전환·게이지·시퀀스 계약이 검증됐다고 보지는 않습니다.
