# DAEMONISM — docs 폴더 안내

기준: 2026-10-15 대화 및 사용자가 업로드한 `2daemonism.zip`, 그 뒤 제공된 Step 03 개별 코드(아직 사용자 실행 성공 보고 없음).

이 폴더는 **게임 실행에 필요한 코드나 리소스가 아닙니다**. Godot에 등록하거나 Autoload로 추가하지 않습니다. 삭제해도 현재의 씬 전환·저장·전투 타이머 코드 실행에는 직접 영향이 없습니다.

그러나 장편 프로젝트에서는 사용자 결정, 임시값, 확정된 인터페이스, 미구현 기능, 검증 여부를 구별해 두는 것이 중요합니다. 새 대화·Work·Codex로 작업을 옮길 때도 이 문서와 **최신 실제 프로젝트 파일**을 함께 전달하면 좋습니다. 문서는 실제 파일의 대체물이 아닙니다.

## 파일별 용도
- `ARCHITECTURE_BASELINE.md` — 게임 전체 규칙, 시스템 책임, 실제 구현/검증 상태, 다음 결정이 필요한 시점. **계속 유지·갱신**.
- `COMBAT_PHASE_BASELINE.md` — 전투 공격/공동 행동 단계의 책임과 현재 Step 03 설계·미구현 기능. **전투 개발 시 계속 유지·갱신**.
- `APPLY_STEP03.md` — Step 03 파일 적용 방법과 검증 순서. **설치 후 참고용**; 매번 재설치할 필요 없음.

## 넣는 방법
1. Windows 파일 탐색기에서 `project.godot` 파일이 들어 있는 DAEMONISM 프로젝트 폴더를 연다.
2. 그 폴더 안의 `docs` 폴더를 연다. 없으면 새로 만든다.
3. 이 폴더의 Markdown(`.md`) 4개를 `docs` 폴더에 복사한다.
4. **Godot 프로젝트 설정이나 씬 노드에는 아무것도 추가하지 않는다.**

## 관리 원칙
- 새 규칙은 `[확정]`, `[유력]`, `[제안]`, `[미정]`을 구별한다.
- 파일에서 확인한 것, 사용자 실행으로 검증된 것, 제공만 된 코드를 구별한다.
- 향후 최신 사용자 결정이 오래된 문서보다 우선한다.
- 문서에 적힌 코드 구조와 실제 로컬 프로젝트가 다르면 **현재 실제 파일을 먼저 확인**한다.
- 저장된 `.md`를 넣었다고 Step 03 실행 검증이 완료되는 것은 아니다.
